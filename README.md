## a. Fundamentals of UI and UX

# UI – User Interface
UI refers to the visual and interactive elements of a website or application. It includes:
Colors and typography
Buttons and icons
Images and layouts
Menus and navigation
Spacing and visual hierarchy

# UX – User Experience
UX refers to the overall experience a user gets while using a product. It focuses on:
Usability
Easy navigation
Accessibility
Efficiency
User satisfaction

## b. Difference Between UI and UX

                UI                                             UX
Focuses on the appearance of a product         Focuses on the overall user experience
Deals with colors, fonts, icons and layouts    Deals with usability and navigation
Makes the interface attractive                 Makes the product easy and satisfying to use
Example: Product card design in Nykaa          Example: Easy product search and checkout

# Real-world example:
 In Nykaa, the attractive colors, product images, buttons and layouts represent UI, while search, filters, reviews, recommendations and easy checkout represent UX. Similarly, Purplle uses its visual branding and promotional layouts as UI, while its product discovery and shopping flow contribute to UX.

## c. Relationship Between UI and UX
UI and UX are closely related and work together.

UX → Plans the user experience → UI → Designs the interface → User interacts with the product → Feedback → Improvement

For example, an Add to Cart button with attractive design is UI. Making sure the button is easy to find, works correctly, and gives feedback after clicking is part of UX.
Therefore, good UI makes a product attractive, while good UX makes it useful and easy to use.
